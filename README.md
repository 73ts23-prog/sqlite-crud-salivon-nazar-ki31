# Моя бібліотека

Салівон Назар, КІ-31. Лабораторна робота 6–7 з баз даних.

Застосунок Flask та SQLite з окремим модулем доступу до даних. Таблиця books має шість полів. Можна додавати, переглядати, редагувати та видаляти книги.

## Запуск

```text
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Відкрити http://127.0.0.1:5087/ . Файл data.db створиться автоматично. Для чистого списку запустити застосунок з новим шляхом у змінній BOOKS_DB.

SQL використовує параметри, введені дані перевіряються. Видалення виконується лише POST-запитом.
